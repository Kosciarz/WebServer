# WebServer

This project contains a simple web server built in C++ using Asio networking library.
It currently only supports HTTP/1.x.

## Setup Instructions

1. Clone the repository.

    ```shell
    git clone https://github.com/Kosciarz/WebServer.git
    ```

2. Build the project.

    ```shell
    mkdir build
    cd build
    cmake ..
    cmake --build .
    ```
